`AdvancedStorageCoreBlockEntity` will gain 4 new fields (`advancedHasSearchBox`, `advancedHasSortBox`, `advancedHasSecurityBox`, `advancedHasStatisticsBox`) alongside the existing `advancedHasCraftingBox`.
